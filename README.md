# تطبيق المحاسب - Daily Accounting App

تطبيق متكامل لإدارة الحسابات والمصروفات اليومية

## 🚀 الميزات

- ✅ إضافة ومتابعة الحسابات اليومية
- ✅ تصنيفات متعددة للمعاملات
- ✅ تقارير شاملة ومتنوعة
- ✅ نسخ إحتياطي واسترجاع البيانات
- ✅ واجهة عربية سهلة الاستخدام
- ✅ دعم RTL (من اليمين لليسار)
- ✅ حفظ البيانات محلياً
- ✅ تصدير التقارير

## 📦 التثبيت

1. قم بفك ضغط الملف
2. افتح ملف `index.html` في المتصفح
3. ابدأ باستخدام التطبيق!

## 📱 الاستخدام

### إضافة حساب جديد
- اضغط على زر + في الأسفل
- أو اختر "إضافة مبلغ" من القائمة

### عرض التقارير
- اضغط على القائمة الجانبية (☰)
- اختر نوع التقرير المطلوب

### النسخ الإحتياطي
- من القائمة الجانبية اختر "حفظ نسخة إحتياطية"
- سيتم تحميل ملف JSON يحتوي على جميع بياناتك

## 🛠️ التقنيات المستخدمة
